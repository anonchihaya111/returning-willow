# 还愿柳 · 解密扩展版

一个可离线游玩的网页调查 demo。打开 `index.html` 即可开始，进度保存在当前浏览器的 `localStorage` 中。

本版沿用原有论坛、旧手机、县志、登记账和照片缓存的主线，并按六站剧情拆解中总结出的方式扩充：不同媒介承担不同证词，同一记录出现版本冲突，关键规则必须由玩家亲手验证，结局回应「谁有权决定一个人是否存在」。新增文本与谜题均为本项目原创，没有复用参考作品的文案或素材。

## 本版新增

- 恢复缺失的 `style.css`，让旧手机、县志、账簿、原契与结局页恢复完整视觉样式。
- 线索由 9 条扩展为 12 条。
- 新增隐藏日记：在旧手机文件页发现文件数与索引数不一致，显示隐藏项目后，将四页临时文件按内容顺序重组。
- 新增古籍校勘：把《柳祠香会簿》残墨对比度拉高，固定显影结果，再补录被 1932 年重修本删掉的旧例。
- 新增柳外三证：从六份材料中找出三份不受论坛后台控制、又明确保有林舟本名的记录。
- 新增第三结局「留名」：完整证据链解锁。它保住林舟存在过的事实，但不能让他回来。
- 结局落款改为调查收束点。愿望柳历年回帖、父母旧红纸、守柳人第一笔账未查完前，不能直接跳到结局。
- 论坛正文和跟帖支持回复与收藏；玩家回复及帖子收藏保存在当前浏览器。
- 「失物招领」改为独立页面。收藏林舟的第 3241 楼后，旧手机会作为待确认物品出现在该页。

## 无剧透游玩顺序

1. 从愿望柳帖找到林舟留下的楼层。
2. 调查旧手机的消息、文件与相册。
3. 阅读《青河县志》，留意目录里的早期抄本。
4. 用本名与凭单查还愿登记，并核验旧照片。
5. 展开原契后，继续调查论坛旧回帖、父母抽屉和第一笔账。
6. 根据古籍旧例建立三处离线存证，再决定如何落款。

## 完整攻略（含全部剧透）

### 找到旧手机

1. 在首页点击热帖「愿望柳」，也可以先进入「乡土民俗」版块。
2. 在帖子内搜索框输入 `林舟`，定位到第 3241 楼。
3. 点击第 3241 楼下方的「收藏」。收藏成功后，这个按钮会显示为「已收藏」。
4. 记下许愿人本名 `林舟` 和自留凭单 `LX0617`。
5. 点击侧栏「失物招领」，进入独立的失物招领页面。
6. 找到新增的「黑色旧手机」，点击「查看林舟的旧手机」。如果没有出现手机，说明第 3241 楼尚未收藏。
7. 输入四位密码 `0616` 解锁手机。

论坛正文和跟帖都可以回复或收藏，但这些操作不影响主线；只有第 3241 楼的收藏是必需步骤。

### 恢复手机记录

8. 在手机「消息」页展开「00:47 · 未发送的语音」，点击「留存这份转写」。
9. 切换到「文件」页，点击「显示隐藏项目」。
10. 在 `._drafts.bin` 项目中点击「恢复临时文件」。
11. 按顺序选择四个片段：`六月十四日` → `六月十五日` → `六月十六日` → `六月十七日`。
12. 点击「按此顺序恢复」，然后点击「留存恢复记录」。

### 查县志与早期抄本

13. 进入「青河县志数字馆」第 119 页。
14. 分别点击两段可交互文字：`所谓还愿，还，归也。`和`录名须用初生之名。`
15. 点击「留存这两处边注」。
16. 打开页面下方出现的《柳祠香会簿》早期抄本。
17. 将「残墨对比度」拉到至少 `72%`，点击「固定显影结果」。
18. 三个补录答案依次选择：`三人`、`初名`、`异处`，然后提交补录。

### 查账并核对旧照片

19. 进入侧栏「民俗愿事登记」。
20. 填写许愿人本名 `林舟` 和自留凭单 `LX0617`，点击「查验这笔愿望」。
21. 在登记结果中点击「查看那张旧合照」。
22. 在手机相册中点击「打开旧缓存对照」，拖动缓存滑杆查看原图。
23. 照片问题选择：林舟位于`姐姐左侧（画面左侧）`，手持`蓝色纸风车`。
24. 点击「留存这段记忆」，然后点击「查看他的原契」。
25. 在原契中点击「展开下半页」，再点击「核对落款，留存完整原契」。

### 完成落款前的三项调查

26. 点击「回看最新回帖」，在愿望柳最新页底部选择「察觉到了什么，记下来」。
27. 返回「民俗愿事登记」，点击「调阅原契」。
28. 点击「去翻父母的抽屉」，选择「纸折在这里。小心展开」，再点击「留存这张红纸」。
29. 再次进入「民俗愿事登记」，点击「调阅原契」，然后点击「查看第一笔账」。
30. 在 2009 年残页中点击「展开这条记录」，再点击「留存这条记录」。

完成这三项调查后，「展期」和「结清」结局都会解锁。

### 三个结局

- **展期**：在原契选择「请求展期」，近亲落款填写 `林晚`，展期申请填写 `暂不结清`。
- **结清**：在原契选择「代为签收」，近亲落款填写 `林晚`，签收文字填写 `还愿`。
- **留名（隐藏结局）**：先完成下面的柳外三证，再回原契选择「在柳外落字」。近亲落款填写 `林晚`，存证文字填写 `林舟在此`。

### 解锁隐藏结局「留名」

31. 进入侧栏「离线存证清单」。
32. 恰好选择以下三项：`旧手机日记恢复包`、`未同步的合照缓存`、`母亲保存的旧红纸`。
33. 不要选择愿望柳帖子、还愿登记或县志：前两项仍受柳控制，县志则没有记录林舟本名。
34. 点击「建立三处校验」，随后点击「返回原契」。
35. 选择「在柳外落字」，填写近亲落款 `林晚` 和存证文字 `林舟在此`。

页面内人名、机构、通知、图片变化、论坛条目、账簿与县志内容均为虚构。配图为写实摄影风格的虚构场景图，工具图标使用随包提供的 Lucide（ISC License）。
